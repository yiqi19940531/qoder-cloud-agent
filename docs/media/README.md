# 演示素材说明

- `01`–`09` 是 2026-10-10 在本地 Web 应用中实测后保存的页面截图：包括 `ask_user` 追问与回答、20 商品结果、独立执行轨迹和远端 Apify MCP `call-actor` 参数。
- `qoder-config-verified.png` 是从 Qoder Agent API 的非敏感返回字段制作的**配置核验摘要**，不是 Qoder 控制台截图；对应的静态 HTML 在 `public/demo/agent-config.html`。
- `demo.mp4` 由这些真实页面截图按流程合成，按 **2×** 压缩播放到 **12 秒**，五个阶段均在视频上方标注关键测试点。它是短演示片，不冒充连续的控制台录屏。
- 演示素材不包含 API Key、PAT、Vault 密钥或本地数据库。内部 Session/Run 标识仅用于说明测试链路，不是访问凭证。
